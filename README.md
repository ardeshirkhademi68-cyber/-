# هم‌صحبت ریژاو

رابط کاربری راست‌به‌چپ و سبک برای پاسخ‌گویی اولیه به مخاطبان پروژه فرهنگی، هنری و تاریخی ریژاو.

## اجرا

یک سرور فایل ایستا اجرا کنید، برای نمونه:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. پاسخ‌های نمونه در `app.js` قابل توسعه‌اند.

## بررسی

```bash
npm test
```
